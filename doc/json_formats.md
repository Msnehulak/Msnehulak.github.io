# How look jsons data look 

## Games
```json 
{
    'type': str,    - Type where game frome
    'name': str,    - Name of game
    'play_time': int,   - How log i play game in seconds
    'link': str,    - Link to game page
    'art': str,     - Link to game cover art (aspect ratio 2.18 / 1)
    'more' {        - More info for game
        'new_tab': bool,    - Is link open in new tab 
    }
}
```
